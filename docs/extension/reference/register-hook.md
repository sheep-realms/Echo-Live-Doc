# 注册器 Hook

## 格式

``` json
{
    "Hook 名称": [
        {
            "registry": "注册表名称",
            "value": {
                "注册项名": "注册项值"
            }
        }
    ]
}
```

## Hook

### `loaded`

在注册表有数据载入后载入扩展数据，推荐使用。

即便没有任何数据载入，注册表也会在即将被读取数据时触发此 Hook 以确保扩展数据可被读取。

### `now`

立即注册数据，这可能会导致意外的载入时机，不建议使用。
