# 简介

扩展是 Echo-Live 的一项针对客制化内容封装和资源共享的解决方案。通过制作扩展，您可以更方便地管理与部署您的客制化内容。

## 为什么要推出扩展系统？

个人的开发精力是有限的，我们希望通过扩展来汇集社区创造力。通过扩展，我们可以让 Echo-Live 具备可被高度客制化的能力，而这正符合 Echo-Live 设计之初所确立的价值观之一 —— 包容。

## 什么时候需要使用扩展？

Echo-Live 作为纯前端产品，本身不具备自动更新升级的能力。如果您为 Echo-Live 修改了除配置以外的其他内容，通过扩展来载入这些内容可以更方便地在不同的版本之间迁移。

如果您需要分享您对 Echo-Live 所做的更改，扩展也是一个很好的共享载体。
